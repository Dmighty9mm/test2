PlebClient for Minecraft Bedrock (Windows 10/11, 64-bit)

Install
  1. Start Minecraft Bedrock (a version from 1.20.80 to 1.26.3).
  2. Inject PlebClient.dll with your DLL injector (for example Fate Injector or
     the injector you already use for other clients).
  3. Press K in game to open the menu (you can change the key there).

Settings and configs are kept in Minecraft's RoamingState\PlebClient folder.
PlebClient doesn't send anything to Flarial's servers.
